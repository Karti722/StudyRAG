# StudyRAG
An applied AI web learning platform, tailored to your quarterly, semesterly classes.
## Synopsis
So what happens when your class relies on proprietory information (powerpoint slides, PDFs, etc) and any info from the internet related to the class can be misleading or in some cases, nonexistent? The answer is StudyRAG, a full stack ai platform in which you put in all your powerpoint slides, PDFs, textbook images, and other non-cheating material and feeds it into a vector database for up to 4 classes. Then, you can ask the application many questions related to the material and vice-versa for test practice. The website can also generate images based off the material if you request it as so.
